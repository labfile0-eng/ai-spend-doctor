How to export Claude API usage and cost as CSV

Short answer: sign in to the Claude Console, open the Cost page (platform.claude.com/cost) or the Usage page (platform.claude.com/usage), pick the month, and press the export button to download a CSV. You need the Developer, Billing or Admin role.

Step by step

  1. Sign in at platform.claude.com with an account in your organization.
  2. In the left menu open Cost for dollar amounts, or Usage for token counts.
  3. Choose the period. The previous full month gives the most useful picture; spike detection needs at least a week of days.
  4. Keep workspace, model and API key set to all, unless you want to check one of them on purpose.
  5. Press the export button to download the CSV.

Anthropic describes both pages, the filters and the export in Cost and usage reporting in the Claude Console.

Cost or Usage: which file to take

FileWhat it containsBest for
CostDollar amounts per model and dayWhat you actually paid, daily spikes
UsageUncached input, cache reads, cache writes and output tokensCache share and how your tokens are made up

If you can, take both. The cost file answers "how much", the usage file answers "why".

If you do not see the pages

Usage and cost reporting is visible to the Developer, Billing and Admin roles. If your account has a different role, ask the organization admin to export the file or to change your role.

If you use the API instead of the Console

Organizations with an admin key can pull the same data from the Usage and Cost API. The cost report returns amounts in cents as decimal strings, so divide by 100 before comparing with your invoice.

Questions

Where do I export Claude API costs?

In the Claude Console, on the Cost page (platform.claude.com/cost) or the Usage page (platform.claude.com/usage). Pick the month and press the export button to download a CSV.

Which role do I need to see Claude API costs?

Anthropic says usage and cost reporting is visible to the Developer, Billing and Admin roles.

Is the Claude Cost API in dollars or cents?

The Usage and Cost API cost report returns amounts in cents as decimal strings. Divide by 100 to get dollars.
