# Agent web-data research pilot

This directory contains a pilot invitation, a proposed contract and a synthetic response example. It is not a deployed retrieval API or a paid product.

- `index.html`: public invitation for agent developers with recurring SaaS pricing tasks.
- `contract.md`: proposed request, evidence, freshness, failure and billing rules.
- `sample-response.json`: explicitly fictional data for discussion; no real vendor prices.

The existing CSV checker is a separate working tool. The new hypothesis needs real tasks, comparison against existing retrieval services and willingness-to-pay validation.
