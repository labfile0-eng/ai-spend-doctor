# First-user pilot

Status: drafts for owner review. Nothing in this folder has been sent or published.

Focus: developers who already pay for Claude or OpenAI API and can export usage/cost data. A chat subscription alone is not sufficient.

Pilot target (not a forecast): 10 voluntarily confirmed checks using a real export, plus 5 actionable pieces of feedback. Demo views are separate. The site has no analytics; do not infer completions or conversion from link clicks or UTM parameters.

1. Validate the new release and obtain one anonymized example of each claimed dashboard-export format. Do not request API keys or complete billing files.
2. The owner invites 5–10 relevant contacts to try the free check. Use the invitation below as a draft.
3. Fix recurring compatibility/understanding problems before widening distribution.
4. Publish one reviewed post on an existing owner-controlled professional channel. Use a synthetic demo screenshot and the direct demo link.
5. Choose one relevant community only after reading its current rules. Do not cross-post identical promotions or request votes.
6. Review useful feedback after 14 days: completed checks, recurring blockers, whether anyone found a useful next action. Keep only aggregate counts and non-sensitive notes.

## Own-channel post draft

An API bill tells you the total. Understanding a spike or a model mix takes another step.

We built AI Spend Doctor to check a usage CSV on your own device. It shows spend spikes, cache/batch coverage when the file supports them, and clearly labelled model-price scenarios. Missing data is disclosed rather than treated as zero.

Free, no signup and no API key. Try the synthetic demo: https://aispenddoctor.com/#demo

We’re looking for feedback from developers with Claude or OpenAI API exports. Was the file read correctly? Was any suggested next step useful? Please don’t share billing files publicly.
