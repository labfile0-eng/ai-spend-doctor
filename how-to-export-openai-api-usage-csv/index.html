How to export OpenAI API usage and cost as CSV

Short answer: open platform.openai.com/usage, choose the organization, projects and period, and use the export option to download the data. You need to be an organization owner or have the Usage Dashboard permission. Dates are in UTC.

Step by step

  1. Sign in at platform.openai.com/usage.
  2. Select the organization. Leave the project selector empty to see all projects, or pick the ones you want.
  3. Choose the reporting period. The previous full month is a good start.
  4. Use the export option on the page to download the data. OpenAI notes there is no limit on the export date range, and long periods may be split into several files.

OpenAI documents access, filters and export in Reviewing API usage and costs.

Two details that change the numbers

  • UTC dates. The dashboard shows data in UTC. A spike that looks like it happened at night in Almaty or New York may belong to the previous or next day in the export.
  • Cached tokens are inside input. In OpenAI usage data input_tokens already includes cached and cache-write tokens. Subtract input_cached_tokens before pricing the rest at the full input rate, or you count the cache twice.

If you use the API instead of the dashboard

With an admin key you can read the same data from the organization Usage and Costs endpoints. Costs come back as amount.value in US dollars, one line item per model and token type, for example gpt-6-sol, cached input.

Questions

Where do I export OpenAI API usage?

On the usage dashboard at platform.openai.com/usage. Choose the organization, projects and period, then use the export option.

Who can see OpenAI API usage?

OpenAI says the dashboard is available to organization owners and to members with the Usage Dashboard permission.

Why do OpenAI usage dates look shifted?

The dashboard and exports use UTC, so activity near midnight in your local time can land on a different day.
